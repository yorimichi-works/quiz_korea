# Season question packages

問題データはアプリ基盤へ直書きせず、シーズン単位で管理する。

- `manifest.json`: 有効シーズンと問題ファイルの対応
- `S1-2026/questions.ko.json`: S1-2026の韓国語問題パッケージ
- `S2-2026/questions.ko.json`: 出題可能2000問の現行韓国語問題パッケージ
- `S2-2026/facts.batch-*.json`: S2で追加した事実と2つの設問表現の監査元データ
- `enabledInSeason: true`: 当該シーズンで出題可能
- `enabledInSeason: false`: 公式情報・出典・表現の再確認まで保留

新シーズンでは新しいフォルダを追加し、確認完了後にmanifestの`activeSeasonId`を切り替える。過去シーズンの問題は上書きしない。

S2はS1で有効だった918問を引き継ぎ、541件の新規事実から1082問を追加する。
逐次表示を活かすため、問題スタイルは次の比率に固定する。

- `standard`: 1700問（85%）
- `wait_for_clue`: 100問（5%）。終盤の決定的な手掛かりを待つ問題
- `reasoning`: 100問（5%）。本文内の複数の手掛かりから導く問題
- `lateral`: 50問（2.5%）。既知の事柄を別角度から結び付ける問題
- `misdirection`: 50問（2.5%）。関係の読み違いと「難解な導入→平易な終盤」の各25問

20ラウンドでは全11カテゴリを必ず含め、難易度を easy 7問・standard 10問・hard 3問に固定する。
同じカテゴリを連続させず、hardの3連続とhard始まりを避ける。特殊問題は序盤・中盤・終盤へ
1問ずつ分散し、最短決着でも少なくとも1問は体験できるようにする。

直近3対戦で実際に表示された同一事実グループは優先的に除外し、再戦時の既視感を抑える。
問題文は句読点で自然に間を取って逐次表示する。解答は最大8個の文字列タイルへ分割し、
候補配置は同じ問題・同じプレイヤーなら再接続後も変えない。

生成は `npm run build:questions`、事実・重複・選択肢の品質検査は
`npm run test:questions`、読み上げ順と待つ駆け引きの検査は
`npm run test:experience` で行う。
